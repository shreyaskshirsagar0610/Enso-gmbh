    Deals and investorsPrototype tested with test records

    One investor and project base in HubSpot, with explained matching

    The problem

    Comparing a project with many investor mandates by hand is repetitive and can lead to inconsistent shortlists.

    What I did

    • HubSpot structure: investors as companies, projects as deals, with matching properties, lists, pipeline and dashboards
    • A weighted matching workflow in n8n that ranks investors and explains every criterion
    • Tested an automatic VDR follow-up task and a required reason for "Not Pursued"
    Today
    Tested with test records, including a Zambia solar + BESS project. Scores show rule-based compatibility, not investment probability.
    Next
    Validate the rules with colleagues, test real records, define shared access
      Finance and controllingLocal demo, shown to my manager

      Cost data into the controlling workbook, with checks and a summary

      The problem

      Moving cost information into large controlling workbooks by hand takes time and can introduce mistakes.

      What I did

      • A bookmarked local upload page: n8n coordinates, a Python helper does the processing
      • Fills actual costs and checks for duplicates and missing or invalid data
      • Creates an Import_Report sheet, a Project_Summary sheet and a budget-versus-cost chart
      • Programmed rules only, no AI needed for this task
      Today
      Works with sample files, demonstrated to my manager with different test cases
      Next
      Real workbooks and source data (BMD exports, CSV or Excel), mapping, validation, shared deployment
        Project managementTeam decision supported

        A tested basis for choosing our project-management tool

        The problem

        The company needed one place for tasks, schedules, dependencies, milestones, budgets and time and cost information.

        What I did

        • Compared four tools on collaboration, scheduling, reporting, hosting and integration
        • Built a local OpenProject demo in Docker: a four-phase project with work packages, Gantt view, dependencies, milestones, budgets and time entries
        • Clarified cloud questions: ten users, IT setup, external access, Outlook reminders, accounting imports, reporting and API
        Today
        The team decided to proceed toward OpenProject Basic Cloud for ten users
        Next
        Setting up the cloud version

            Backup for the discussion

            Starting points for a simple AI guideline

            Approved tools onlyCompany accounts with data-processing agreements, no personal AI accounts for company data.
            Data traffic lightPublic: fine. Internal: approved tools. Confidential teasers, data rooms and investor data: only after checking NDA terms and hosting.
            A person reviewsEvery AI output is checked before it leaves the company, as in my workflows.
            AI literacyA short session for staff. Under the EU AI Act, companies using AI must take measures to support their staff's AI literacy.
            One registerWhich AI tools and automations run, who owns them, which data they use and where they are hosted.
            Rules firstProgrammed rules where they are enough, AI only where documents need interpreting. Compliance involved early.

            Source on AI literacy: KI-Campus, AI Omnibus and Article 4 (2026)
